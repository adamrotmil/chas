# Charles model starter data

This package is generated by CharlesOps as a trainer-ready starter artifact.

- `charles_sft.jsonl` contains supervised fine-tuning examples.
- `charles_dpo.jsonl` contains preference pairs.
- `charles_sft.train.jsonl` and `charles_sft.val.jsonl` are deterministic split outputs when created.

Every row is newline-delimited UTF-8 JSON. Run `python scripts/check_jsonl.py ...` before training.
